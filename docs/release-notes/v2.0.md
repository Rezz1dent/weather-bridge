## Русский

**Weather Bridge 2.0** — мост, который раньше назывался Breezy Bridge, теперь в отдельном репозитории.

- Новое имя и новый ID приложения (`com.rezz1dent.weatherbridge`). Устанавливается как новое
  приложение: удалите Breezy Bridge, заново дайте доступ к Breezy и включите Weather Bridge в
  настройке «Оповеститель обновления» в Breezy. Формулы в KWGT не меняются (`$br(breezy, …)$`).
- Вид осадков сейчас и завтра: `precip_now_type`, `tomorrow_precip_type` (rain / snow / mix) и
  подходящие иконки `precip_now_icon`, `tomorrow_precip_icon` (`water-outline`, `snowflake`,
  `snowflake-melt`).
- Подписан постоянным ключом: следующие версии ставятся поверх, без удаления.

**Breezy Minimal 7.6** (виджет KWGT)

- Капля, снежинка или снежинка с каплей — для дождя, снега и снега с дождём; глобальная
  переменная `precip_test` показывает каждый вариант.
- Строки берут шрифт крупнее, когда всё помещается, и мельче, когда значения длинные.

## English

**Weather Bridge 2.0** — the bridge formerly called "Breezy Bridge", now in its own repository.

- New name and app ID (`com.rezz1dent.weatherbridge`). It installs as a new app: remove
  Breezy Bridge, allow access to Breezy again and enable Weather Bridge in Breezy's
  "Update Notifier" setting. KWGT formulas stay the same (`$br(breezy, …)$`).
- Kind of precipitation now and tomorrow: `precip_now_type`, `tomorrow_precip_type`
  (rain / snow / mix) and matching icons `precip_now_icon`, `tomorrow_precip_icon`
  (`water-outline`, `snowflake`, `snowflake-melt`).
- Signed with a permanent key: later versions install over this one.

**Breezy Minimal v7.6** (KWGT widget)

- Drop, snowflake or snowflake with a drop for rain, snow and sleet; global `precip_test`
  shows each of them.
- Rows pick a larger font when the values fit and a smaller one when they would overlap.
